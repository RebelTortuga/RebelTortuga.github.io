# Security Policy

## Supported versions

Security fixes apply to the current `main` branch and the live website at https://rebeltortuga.github.io/. Historical commits and older copies are not maintained.

This policy covers this website repository. For a vulnerability in a linked toolkit or ComfyUI project, report it through that project's repository.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting form](https://github.com/RebelTortuga/RebelTortuga.github.io/security/advisories/new) for this repository. You can also open the repository's **Security** tab and select **Report a vulnerability**.

Include:

- The affected URL, file, or commit.
- A clear description and steps to reproduce the issue.
- The potential impact and a minimal proof of concept, if available.
- Any suggested mitigation.

Do not include passwords, access tokens, personal information, or other secrets. Do not disclose an unresolved vulnerability in a public issue or pull request.

## Review and disclosure

The maintainer will review reports, request clarification when needed, and coordinate any fix and public disclosure through the private report. Response and resolution times depend on availability and the issue's complexity; no guaranteed response deadline or paid bounty is offered.

Test only with accounts and data you control. Avoid disrupting the website, accessing other people's data, or testing third-party services linked from the site.

## Other issues

Use ordinary GitHub issues for non-security bugs, documentation problems, and broken links.
