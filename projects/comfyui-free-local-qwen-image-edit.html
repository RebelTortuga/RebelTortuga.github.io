Set up the workflow in ComfyUI

Install the documented dependencies first, then choose the edit mode that matches the change you want to make.

  1. Install or update a local ComfyUI setup, then add the exact custom nodes and model files listed in the project dependencies.
  2. Restart ComfyUI, refresh the browser, and drag the included workflow.json onto the canvas.
  3. Use a plain-language instruction for mode 1, or paint and save a mask in ComfyUI’s Mask Editor for mode 2.

Requirements

  • A working local ComfyUI installation with the exact custom node types listed in the project dependencies.
  • Install the listed model files and custom nodes separately; they are not included in the ZIP.
  • Sufficient GPU/system memory and disk space for the selected models and settings. A hardware minimum has not been verified.
  • Internet access is needed for initial downloads. Inference runs locally; no paid API is required.
