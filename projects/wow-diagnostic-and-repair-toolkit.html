Requirements

  • Windows 10/11 with Windows PowerShell 5.1, Windows Forms, and Windows Script Host.
  • PowerShell 7, Python, Git, and third-party PowerShell modules are not required.
  • Keep all supplied launcher, script, and guide files together. Some repair operations request administrator approval.
