Repo-Update-Manager

A free Windows desktop app for checking selected GitHub and npm updates while keeping installations under your control.

Download v0.1.0 for WindowsView source

Early Windows preview

Extract the portable x64 ZIP and run Repo-Update-Manager.exe. No .NET runtime is required. Local data is stored in %LOCALAPPDATA%\RebelTortuga\RepoUpdateManager.

SHA-256: 866D5A8188F39726741F5AB6599AF0195EACDD89C933456F9508436102D93545

Check what matters

  • Track GitHub releases, tags, and commits.
  • Filter release streams and compare recorded versions.
  • Check npm package identities and versions.
  • Keep entries locally, with JSON import and export.

Updates stay deliberate

Checks are read-only. Automatic updates are limited to explicitly approved clean Git worktrees that exactly match a commit-tracked GitHub repository.

npm, ZIP, installer, plugin, skill, and manual update methods remain manual in v0.1.0.

What comes next

Future work may include signed installer distribution, broader verified update methods, activity history, and Linux/macOS validation. Planned work is not part of this release.
